This dry box is made of plexiglass to provide a clear view of the filament. It uses an Arduino Nano, a DHT11 sensor for temperature and humidity measurement, and a liquid crystal display (LCD) to show the data.

I laser-cut a rectangular plexiglass panel, although it can also be cut using a saw. I then heated it to shape it before gluing it in place on the bottom piece.
